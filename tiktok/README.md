# TikTok-ролик и обложка AROMIO

Вертикальный ролик в эстетике «синего часа» (окно → птицы над городом →
флакон → карточка бренда) и квадратная обложка для музыкальных сервисов
и профиля. Всё рисуется кодом на `<canvas>`, без стоковых видео и фото.

```
scene.js     вся графика: слои, сцены, флакон, титры, обложка
scene.html   холст 1080×1920 → renderFrame(t)
cover.html   холст 1500×1500 → renderCover()
fonts.css    Inter + Cormorant Garamond (OFL), вшиты base64
render.py    съёмка кадров через Playwright + сборка в H.264
out/         готовые файлы
```

## Сборка

```bash
pip install playwright imageio-ffmpeg
python3 render.py preview 1.5 9 14      # отдельные кадры в out/preview/
python3 render.py video                 # out/aromio-tiktok.mp4
python3 render.py cover                 # out/aromio-cover-1500.jpg + 640
```

Сцена детерминированная: `renderFrame(t)` рисует один и тот же кадр для
одного `t`, поэтому кадры снимаются пошагово, а не записью в реальном
времени — скорость машины на результат не влияет. Playwright берёт
chromium из окружения (`/opt/pw-browsers`), либо путь задаётся через
`CHROME_PATH`.

## Что где править

| Хочу поменять | Где |
|---|---|
| строки на экране и тайминг | `LINES` в `scene.js` |
| порядок и длительность сцен | `SCENES`, `DURATION` |
| цвет неба | `SKY_*` и градиенты в `buildSky*` |
| форму флакона | `bottlePath` / `drawBottle` |
| композицию обложки | `renderCover` |

Слова внутри строки появляются по одному: `app` — длительность появления,
`step` — пауза между словами (обе в `drawLines`).

## Звук

Ролик рендерится **без звуковой дорожки** — трек накладывается уже в
TikTok, из встроенной библиотеки: так композиция остаётся лицензированной
площадкой, ролик попадает в ленту этого звука, и нет риска, что видео
заглушат за музыку. Тайминг титров рассчитан на спокойный бит ~80–90 BPM;
если трек нужно попасть в акцент, двигаются значения `t` в `LINES`.

## Обложка

`out/aromio-cover-1500.jpg` — квадрат 1500×1500, `-640` — та же картинка
под требования профиля (минимум 640×640, JPEG). Логотипы музыкальных
сервисов в обложку не ставятся: их гайдлайны это запрещают, площадка
рисует свой интерфейс поверх.
