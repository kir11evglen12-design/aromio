# AROMIO — PARFUM’S

Витрина нишевой парфюмерии: презентация ароматов в духе premium-бренда
плюс рабочая логика магазина (каталог, карточка товара, корзина, аккаунт).

## Стек

| Слой | Выбор | Почему |
|------|-------|--------|
| UI | React 19 + TypeScript | типизированные данные товаров и состояние магазина |
| Сборка | Vite + `vite-plugin-singlefile` | продакшн — один самодостаточный `docs/index.html`: работает на GitHub Pages, в превью и с `file://` |
| Стили | Tailwind v4 (`@theme`-токены) + компонентный CSS | утилиты для раскладки, обычные правила для 3D-сцены флакона и оверлеев |
| Анимации | GSAP + ScrollTrigger | scrub-эффекты, pin, batch-reveal |
| Скролл | Lenis | инерционная прокрутка, синхронизирована с ScrollTrigger через один rAF |
| Иконки | lucide-react | единый штрих, без эмодзи в интерфейсе |
| Шрифты | Cormorant + Inter (Google Fonts) | высококонтрастная антиква для витрины, гротеск для интерфейса |

Next.js не используется намеренно: витрина не нуждается в SSR и роутинге,
а Vite даёт сборку в один файл — иначе результат нельзя открыть по прямой ссылке.

Three.js / R3F тоже не подключены: флаконы собраны на CSS 3D. Это несколько
килобайт против ~600 КБ рантайма, а без HDRI-окружения WebGL-стекло выглядело бы
хуже нынешней отрисовки. Если понадобится фотореалистичный рендер — это
изолированная замена компонента `Bottle`.

## Важно про аккаунты

Бэкенда нет, поэтому вход клиентский. Пароль никогда не сохраняется — только
PBKDF2-SHA256 (150 000 итераций) со случайной солью. Это честно ограждает пароль
от чтения из localStorage, но не заменяет серверную авторизацию: данные живут
в одном браузере и доступны тому, у кого есть доступ к устройству.

## Ассортимент

В витрине три дома: **Dior**, **Louis Vuitton** и **Valentino** — по четыре
аромата у каждого. Товары подписаны реальными названиями и брендами: магазин
выступает ретейлером, а не выдаёт чужие ароматы за собственные.

Фотографии флаконов Valentino и фотографии ингредиентов предоставлены
владельцем магазина, который подтвердил права на их использование.

## Фон и тема

Интерфейс тёмный: near-black подложка, тёплый off-white текст, один песочный
акцент. Токены в `@theme` сохраняют роли — «paper» это всегда страница,
«ink» это всегда то, что на ней написано, поэтому смена палитры не требует
переписывать правила.

Фон — живая деформированная сетка (`src/components/Backdrop.tsx`): 44×44
полилинии на canvas, смещённые слоями синусов плюс два бегущих завихрения.
Рисуется ~40 кадров в секунду, двигается вместе с прокруткой, замирает
в фоновой вкладке и при `prefers-reduced-motion`.

## Пирамида нот

Пирамида читается буквально: **2 плитки сверху** (верхние ноты), **3** в сердце,
**4** в базе — ряды центрированы, а плитки уменьшаются по мере расширения,
поэтому блок сужается кверху.

`src/data/noteImages.ts` сопоставляет ноту с фотографией по ключевому слову —
сейчас это 37 сырьевых материалов, нарезанных из присланных листов. Порядок
правил важен: составное название стоит выше слова, которое в нём есть
(«розовый перец» — до розы, «зелёное яблоко» — до яблока, «лист фиалки» — до
зелени).
Нота без фотографии (например, «мускатный орех») отрисовывается плиткой
семейства ингредиентов из `src/lib/notes.ts` — пирамида остаётся полной,
без выдуманных изображений.

## Редакционный слой

`src/data/facts.ts` держит три вида текста: факт о сырье (жасмин снимают до
рассвета, уд появляется меньше чем у 2% деревьев), история конкретного аромата
(год, парфюмер, замысел) и предыстория дома. Плитка ноты с фактом кликабельна —
история раскрывается под пирамидой, а не в подсказке, чтобы работало и на
телефоне.

Факты — общеизвестные сведения о парфюмерном сырье и домах. Перед публикацией
магазина их стоит сверить: у окружения, где собиралась сборка, нет доступа в
сеть для проверки.

## Объёмы

У каждого аромата свои варианты флакона: Dior — 50/100/125 мл,
Louis Vuitton — 100/200 мл, Valentino — 50/100/150 мл. Выбор объёма живёт
в карточке товара, цена пересчитывается, а строка корзины хранит выбранный
объём. В каталоге цена показана как «от …».
