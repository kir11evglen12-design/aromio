# Логотипы домов

Положите сюда файл с именем дома в нижнем регистре, где пробелы заменены
дефисами, — и плитка на странице «Дома» сама подхватит его вместо
нарисованной надписи. Перезапуск сборки не нужен, только пересборка.

    louis-vuitton.png
    tom-ford.svg
    maison-francis-kurkdjian.webp

Подходят .svg, .png, .webp и .jpg. Лучше всего смотрится логотип на
прозрачном или белом фоне, примерно 400×220.

Сейчас папка пуста намеренно: сеть этого окружения не выпускает запросы
наружу (прокси отвечает 403 на CONNECT), поэтому логотипы не скачаны, а
не подставлены наугад. До тех пор каждая плитка рисует название дома
шрифтом витрины.
