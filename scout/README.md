# Meridian Scout

Сканер торговых сетапов. Считает по свечам биржи, принимает алерты
TradingView, присылает находки в Telegram и показывает их на своей странице.

Это не советник и не автотрейдер. Он находит условия, у которых есть имя,
и называет цену, на которой идея перестаёт быть верной. Что с этим делать —
решаете вы.

---

## Коротко, что это умеет

* Следит за списком пар на нескольких таймфреймах и проверяет их на каждом
  закрытии свечи.
* Ищет четыре вещи: **пробой уровня с ретестом**, **откат в тренде к EMA21**,
  **выход из сжатия** и **дивергенцию RSI**.
* На каждую находку даёт вход, стоп, две цели, соотношение риска к прибыли,
  размер риска в процентах и список причин, по которым она найдена.
* Шлёт находку в Telegram и пишет в файл. Один и тот же сетап на соседних
  свечах не повторяет.
* Принимает вебхуки TradingView: когда там срабатывает ваше оповещение,
  Scout сразу пересчитывает эту пару и присылает разбор.

## Чего он не умеет — и почему

**TradingView не отдаёт данные графиков.** Публичного API у них нет ни для
кого; то, что вы видите на сайте, рисует их собственный виджет. Поэтому весь
анализ идёт по свечам биржи (Binance, при недоступности — Bybit). Для спота
это те же самые свечи, которые TradingView рисует для этой пары.

**Вебхуки TradingView — только на платных тарифах.** Это их ограничение.
Без платного тарифа Scout всё равно работает: он сам ходит за свечами по
расписанию, просто теряется возможность дёрнуть его вашим оповещением.

**Он не предсказывает.** Оценка «очки» — это не вероятность, а счётчик
подтверждений: сколько условий смотрят в одну сторону. Сетап с 90 очками
проигрывает так же легко, как с 50.

## Установка

Нужен Node.js 18 или новее — больше ничего, зависимостей нет.

```bash
cd scout
node scout.js selftest
```

`selftest` проверяет четыре вещи по очереди и честно говорит, что не прошло:

1. **Арифметику** — индикаторы и детекторы на заранее построенных рядах,
   где известно, какой паттерн внутри. Работает без интернета.
2. **Настройки** — список пар, таймфреймы, секрет вебхука, Telegram.
3. **Биржу** — реально ли приходят свечи и что детекторы говорят прямо сейчас.
4. **Telegram** — отправляет в ваш чат проверочное сообщение.

## Запуск

```bash
node scout.js scan     # один проход и выход
node scout.js watch    # проход на каждом закрытии свечи
node scout.js serve    # то же плюс страница и приём алертов TradingView
```

Страница по умолчанию на `http://127.0.0.1:8787`.

Флаги перекрывают настройки на один запуск:

```bash
node scout.js scan --symbols BTCUSDT,ETHUSDT --tf 1h,4h --min-score 60
node scout.js scan --dry          # ничего не отправлять, только показать
```

## Настройка

Три слоя, каждый перекрывает предыдущий: значения по умолчанию →
`scout.config.json` → переменные окружения → флаги командной строки.

```bash
cp scout.config.example.json scout.config.json
```

| Что | Где | По умолчанию |
| --- | --- | --- |
| Пары | `symbols`, `SCOUT_SYMBOLS` | BTCUSDT, ETHUSDT, SOLUSDT |
| Таймфреймы | `timeframes`, `SCOUT_TIMEFRAMES` | 15m, 1h, 4h |
| Порог очков | `minScore`, `SCOUT_MIN_SCORE` | 45 |
| Пауза между одинаковыми сетапами | `cooldownBars` | 6 свечей |
| Источники свечей | `sources`, `SCOUT_SOURCES` | binance → bybit |
| Адрес и порт | `host`, `port` | 127.0.0.1:8787 |

**Секреты — только в переменных окружения**, не в файле настроек:

```bash
export TELEGRAM_TOKEN=123456:AA...
export TELEGRAM_CHAT_ID=987654321
export SCOUT_SECRET=...            # node scout.js secret
```

## Telegram

1. Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`. Он
   вернёт токен вида `123456:AA...` — это `TELEGRAM_TOKEN`.
2. Напишите своему новому боту любое сообщение (иначе он не имеет права
   писать вам первым).
3. Узнайте номер чата: откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе будет
   `"chat":{"id":987654321`. Это `TELEGRAM_CHAT_ID`.
4. `node scout.js selftest` — последним пунктом он пришлёт в чат проверку.

## TradingView

```bash
node scout.js secret     # сгенерировать секрет и прописать его
node scout.js alert      # покажет адрес вебхука и текст сообщения
```

В TradingView: **Создать оповещение** → вкладка **Уведомления** → включить
**Webhook URL** и вставить адрес. Текст из `node scout.js alert` вставить в
поле **Сообщение** на вкладке «Настройки»:

```json
{"secret":"ВАШ_СЕКРЕТ","symbol":"{{ticker}}","tf":"{{interval}}","price":"{{close}}","note":"{{strategy.order.alert_message}}"}
```

Без секрета `/tv` не принимает ничего и отвечает 503 — это нарочно: адрес
вебхука виден всем, кто до него дотянется.

**TradingView должен уметь достучаться до вашей машины.** `127.0.0.1` из
интернета недоступен. Варианты: туннель (`cloudflared tunnel`, `ngrok http
8787`) или запуск на сервере. Если открываете порт наружу — оставьте
`host` на `127.0.0.1` и пустите наружу только туннель, иначе вместе с
вебхуком в интернет уедет и страница со всеми находками.

## С телефона

Коротко: **запускать с телефона обычно не нужно.** Scout — служба, ей нужно
работать постоянно и ходить в сеть, а телефон для этого худшее место:
система усыпляет фоновые процессы, сеть меняется, батарея садится. Правильно
— пусть считает компьютер или сервер, а телефон получает результат.

### 1. Telegram — основной путь

Ничего открывать не надо. Scout работает где угодно, находки приходят в
Telegram на телефон сами, со входом, стопом и целями. Для этого телефон
вообще не участвует в работе — только читает.

### 2. Страница с телефона по домашнему Wi-Fi

Если Scout запущен на компьютере в той же сети:

```bash
node scout.js serve --host 0.0.0.0
```

Он напечатает адрес вида `http://192.168.1.50:8787` — его и открыть в
браузере телефона. Страница сделана под телефон: карточки сетапов идут в
одну колонку.

Учтите: с `0.0.0.0` страница открыта **всем в этой сети**. Дома это обычно
нормально, в кафе или в общежитии — нет.

### 3. Запустить сам сканер на телефоне: Android

Это правда работает — через **Termux** (ставить из F-Droid, версия из
Google Play давно не обновляется):

```bash
pkg update && pkg install nodejs git
git clone https://github.com/kir11evglen12-design/aromio
cd aromio/scout
node scout.js selftest

export TELEGRAM_TOKEN=123456:AA...
export TELEGRAM_CHAT_ID=987654321

termux-wake-lock        # иначе Android усыпит процесс
node scout.js watch
```

Чтобы не умирало через полчаса: в настройках Android снять с Termux
ограничение батареи («Батарея» → «Без ограничений»). И всё равно это
компромисс — телефон перезагрузится, и надо будет запускать заново.

### 4. iPhone

Node.js на iOS нет и не будет — Apple не разрешает. Варианты ровно два:

* **Telegram** — как в пункте 1, Scout работает на компьютере или сервере;
* **SSH** — поставить Termius или Blink Shell, подключиться к своему
  серверу и управлять оттуда. Телефон при этом только терминал.

### 5. Чтобы работало всегда: сервер

Самый надёжный вариант — самый дешёвый VPS. Файл
`/etc/systemd/system/scout.service`:

```ini
[Unit]
Description=Meridian Scout
After=network-online.target

[Service]
User=scout
WorkingDirectory=/home/scout/aromio/scout
Environment=TELEGRAM_TOKEN=123456:AA...
Environment=TELEGRAM_CHAT_ID=987654321
Environment=SCOUT_SECRET=...
ExecStart=/usr/bin/node scout.js serve
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now scout
journalctl -u scout -f        # смотреть, что он делает
```

Дальше телефон не нужен вообще: сервер считает, Telegram присылает.

### Вебхук TradingView и телефон

TradingView шлёт запрос **на ваш адрес**, а телефон в мобильной сети из
интернета недоступен — оператор прячет его за общим адресом. Поэтому
вебхуки работают только с сервера или через туннель
(`cloudflared tunnel --url http://localhost:8787`). На самом телефоне
вебхук не примете; расписание при этом работает как обычно.

## Что именно он ищет

Каждый детектор смотрит только на закрытые свечи и строит стоп от структуры,
а не от процента.

**Пробой уровня и ретест.** Берётся подтверждённый свинг-максимум (или
минимум) за последние 40 баров, закрытие за него минимум на 0,25 ATR, возврат
к уровню в пределах трети ATR и закрытие обратно на стороне пробоя. Стоп —
за экстремум движения после пробоя.

**Откат в тренде к EMA21.** EMA50 и EMA200 разведены минимум на половину
ATR (иначе это не тренд, а разметка), EMA21 идёт в ту же сторону, свеча
коснулась EMA21 и закрылась обратно, RSI без перегрева. Стоп — за минимум
последних четырёх баров.

**Сжатие и выход из диапазона.** Ширина двадцати баров в ATR — в нижних 30 %
от последней сотни, закрытие за границу, объём выше обычного. Цель — высота
диапазона от границы, вторая — две высоты. Стоп за баром пробоя, а не за
дальней границей: иначе идея рискует высотой диапазона ради высоты
диапазона.

**Дивергенция RSI.** Два свинга подряд, второй экстремальнее первого минимум
на 0,3 ATR, RSI при этом развернулся минимум на 3 пункта и остаётся в своей
зоне. Сигнал считается только после того, как забран промежуточный
экстремум. Стоп за экстремумом — у этого сетапа он самый широкий, смотрите
на «риск % от цены».

### Очки

Начинается с 25 и растёт за совпадения: сторона EMA200 (+15), правильный
порядок средних (+10), согласие старшего таймфрейма (+20, против — −15),
объём выше обычного в полтора раза (+12), соотношение риска к прибыли
(+6…+18). Максимум 100. Порог по умолчанию — 45.

### Почему сетапов мало

Так и должно быть. На трёх парах и трёх таймфреймах несколько находок в день
— нормальный результат, а «ничего не нашлось» — тоже результат. Сканер,
который находит что-то каждый час, находит шум.

## Проверка

```bash
npm test
```

Три набора, все без интернета:

* `ta.test.cjs` — индикаторы на рядах, где ответ известен руками.
* `setups.test.cjs` — детекторы на синтетических графиках, в каждый из
  которых паттерн заложен нарочно. Проверяется и обратное: на ровном рынке,
  на прямой вверх и на прямой вниз не должно находиться ничего. Каждый
  паттерн проверяется ещё и отражённым — шорт обязан считаться так же, как
  лонг.
* `service.test.cjs` — хранилище, разбор вебхука, HTTP: неверный секрет,
  слишком большое тело, попытка выйти из `public/`, отсутствие секрета в
  выдаче `/api/state`.

Живая биржа и Telegram проверяются отдельно — `node scout.js selftest`,
уже на вашей машине.

## Как всё устроено

```
scout.js            командная строка
lib/ta.js           индикаторы: SMA, EMA, Wilder, RSI, ATR, свинги
lib/setups.js       четыре детектора, общая сборка и оценка сетапа
lib/market.js       свечи с биржи, отбрасывание незакрытого бара
lib/scanner.js      обход списка, дедупликация, отправка
lib/store.js        один JSON-файл с находками и алертами
lib/notify.js       консоль, файл, Telegram
lib/tv.js           разбор вебхука TradingView и проверка секрета
lib/server.js       страница и /tv
public/             страница: список находок и виджет TradingView
tests/              наборы проверок и синтетические графики
```

Ни одной зависимости. Всё, что читает этот файл, можно открыть и прочитать.
