Чего на этой странице нет

Она считает, только пока открыта, и ничего никуда не шлёт. Постоянное наблюдение, сообщения в Telegram и приём алертов TradingView — это уже программа, которую надо запустить у себя: 

git clone https://github.com/kir11evglen12-design/aromio
cd aromio/scout
node scout.js selftest
node scout.js serve

Нужен Node.js 18 и выше. Зависимостей нет. Как настроить Telegram и TradingView.

Данные — публичные свечи Binance, при отказе Bybit. Сетапы считаются в вашем браузере, никуда не отправляются и нигде не сохраняются, кроме списка пар в памяти этого браузера.

Scout показывает условия, которые он умеет распознавать, и цену, на которой идея перестаёт быть верной. Это не совет и не прогноз: решение и размер позиции — ваши.
